Why JuliaGeo

One ecosystem,
three guarantees.

Speed without sacrificing readability. A common interface across every supported format. Source code that doubles as documentation.

Fast

Pure Julia, JIT-compiled. Outperforms Shapely and most R libraries on standard geometry benchmarks.

Universal

Built on GeoInterface.jl. Mix shapefiles, GeoJSON, GeoArrow, ArchGDAL — same functions everywhere.

Literate

Source code is the documentation. Every method ships with executable examples and prose-explained math.

Example

Polygon intersection in 4 lines.

Same syntax for any GeoInterface-compatible geometry — Shapefile records, GeoJSON features, ArchGDAL geometries.

using GeometryOps as GO
using GeoInterface as GI

# Two overlapping unit squares
a = GI.Polygon([[(0,0), (2,0), (2,2), (0,2), (0,0)]])
b = GI.Polygon([[(1,0), (3,0), (3,2), (1,2), (1,0)]])

result = GO.intersection(a, b)
GO.area(result)  # → 2.0

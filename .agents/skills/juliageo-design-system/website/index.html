intersection.jl 
using GeometryOps as GO
using GeoInterface as GI

# Two overlapping polygons
a = GI.Polygon([[(0,0), (2,0),
                  (2,2), (0,2), (0,0)]])
b = GI.Polygon([[(1,0), (3,0),
                  (3,2), (1,2), (1,0)]])

result = GO.intersection(a, b)
GO.area(result)  # → 2.0

Why JuliaGeo

Built for scientists who refuse to choose between speed and clarity.

Every package is written in idiomatic Julia. Read the source, extend it, dispatch on it. No glue code, no opaque shared libraries.

Blazing fast

Outperforms Shapely, GEOS, and most R equivalents on geometry benchmarks thanks to Julia's JIT compiler and zero-allocation patterns.

One interface, every format

Built on GeoInterface.jl. Mix shapefiles, GeoJSON, GeoArrow, ArchGDAL — same functions work across every supported source.

Literate documentation

Source code is the documentation. Every method ships with executable examples and prose-explained algorithms via Literate.jl.

Composable

Multiple-dispatch lets you extend any operation for new geometry types or coordinate spaces — no monkey-patching, no inheritance hacks.

Full CRS support

Reproject between any coordinate reference systems via Proj.jl. Handle datums, geodesics, and spherical operations correctly.

Community-driven

Maintained by researchers and engineers across academia and industry. PRs welcome; issues triaged weekly.

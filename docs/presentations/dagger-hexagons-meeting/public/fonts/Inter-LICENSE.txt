licence text was not fabricated here rather than risk shipping an
inaccurate copy.

Before distributing this deck or its build output, drop the canonical
OFL.txt in beside this file. It ships with every Inter release:

    https://github.com/rsms/inter/blob/master/LICENSE.txt
    https://fonts.google.com/specimen/Inter  (download includes OFL.txt)

The OFL requires that the licence and copyright notice accompany the
font whenever it is redistributed, so this is a real obligation for a
deck that gets exported, hosted or handed round — not a formality.

JuliaMono, in this same directory, does ship its full licence text; see
JuliaMono-LICENSE.txt for the shape the finished file should take.

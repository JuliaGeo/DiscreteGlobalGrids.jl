  are `function f end`. Both trees are STI trees with `SphericalCap` node

  are chunk numbers.

## The `build_weights!` seam

    build_weights!(coo::WeightCOO, method, dst_space, dst_inds, src_space, src_inds)

`WeightCOO(ndst)` holds `rows`, `cols`, `vals`, `denom` (length `ndst`, zeroed)
and `hasdenom`. `addweight!(coo, j, k, w)` and `adddenom!(coo, j, d)` take
**chunk-local** indices: `j` is a position within `dst_inds`, `k` within
`src_inds` — never a cell position. `adddenom!` is what flips `hasdenom`; a
block built without it finalizes as a raw sum. Blocks over the same destination
chunk sum their denominators, so a builder reports only its own source chunk's
share.

Partition invariant, documented on the hook: read geometry anywhere, emit only
for source cells in `src_inds`.

## `test/toyspaces.jl`

Code against this without reading it.

**`ToyLonLatSpace(nlon, nlat; lon = (-180, 180), lat = (-90, 90), chunks = (nlon, nlat))`**
— regular lon–lat grid on the unit sphere, degrees. `chunks` is the chunk
**size** in cells `(along lon, along lat)`; the default is one chunk. Position
`i` of cell `(ix, iy)` is `ix + (iy - 1) * nlon` (longitude fastest).
Implements the entire contract including `cellat` and `cellcentroid`;
`hascellchart` is `true`; `manifold` is `GOCore.Spherical(; radius = 1.0)`.
`cellindices` returns a `UnitRange` exactly when chunks span the full longitude
row, a `Vector{Int}` otherwise. `cellat` wraps longitude, returns `nothing`
outside coverage, and assigns a shared boundary east/north (outer boundary
inward).

Toy-only helpers: `cellsubscript(space, i) -> (ix, iy)`,
`cellposition(space, ix, iy) -> Int` (the chart), `cellbounds(space, i) ->
(lon_lo, lon_hi, lat_lo, lat_hi)`, `cellcorners(space, i) -> NTuple{4,USPoint}`
(SW, SE, NE, NW), `graticule_area(space, i)`, `nchunklon`/`nchunklat`,
`chunksubscript`, `dlon`/`dlat`.

Cells are 4-corner **geodesic quads**, counter-clockwise seen from outside,
polar duplicate corner dropped. They tile the sphere exactly, so a global
space's polygon areas sum to `4π` — as do its `graticule_area`s, which are the
separate analytic quantity `Δλ (sin φ_hi − sin φ_lo)`. The two are **not** equal
per cell and the difference has no fixed sign (see the docstring); do not assert
one against the other.

**`ToyCapTree(space, indices)`** — flat one-node STI tree with stored
`SphericalCap` extents, `node_extent_is_expensive = false`. The subset
constructor is the chunk-restricted cell tree a builder works against; it also
implements `Trees.ncells`, `Trees.getcell`, and `GOCore.best_manifold`, so
`ConservativeRegridding` can consume it. `celltree`/`chunktree` return these.
Chunk extents are bounded by the chunk's cells' corners, so they cover.

**`ToyDiagonalMethod(; scale = 1.0, withdenom = true)`** — pairs cells by
identical position and emits `scale` on the diagonal, reading no geometry. Over
a space onto itself it is `scale × I`: `Weighted` returns the field unchanged,
`Extensive` returns it times `scale`. `withdenom = false` produces a block with
no denominator.

Also exported from the file: `toy_point(lon, lat)`, `toy_lonlat(p)`,
`toy_cap(points)`, `TOY_FULL_SPHERE`.

## Tests

`test/runtests.jl` includes `toyspaces.jl`, runs three T1 testsets (toy space
contract, weight blocks, unimplemented hooks), then the six per-task files, each
a one-assertion stub naming its owner. T1's own assertions: chunks partition
positions, full-width chunks are `UnitRange`s, `cellat ∘ cellcentroid == id`,
coverage returns `nothing` outside, graticule and polygon areas each sum to
`4π`, orientation is CCW-from-outside, chunk caps cover their cells' corners and
stay under `π/2` on a regional space, `ToyDiagonalMethod` builds a `2.0 * I(8)`
block with a matching denominator, no-denom builders yield `denom === nothing`,
`Conservative()` errors informatively, `Weighted(1.5)` throws.

## Deviations from the tasks doc, and why

1. **`GeoInterface` added as a dep.** `getcell` returns a GI polygon and the toy
   space constructs `GI.Polygon`/`GI.LinearRing`; reaching them through
   `GeometryOps` internals would be fragile.
2. **`nchunks(space)` added to the contract.** Chunk numbers are the chunk
   tree's leaf indices and something has to bound them.
3. **`cellindices` returns `AbstractVector{Int}`, not a `range`.** A 2-D raster
   chunk is not contiguous in position space under any single flattening. Spaces
   return a `UnitRange` where they can, and the docstring tells callers to test
   rather than assume.
4. **`WeightCOO` + `addweight!`/`adddenom!` invented and placed in
   `methods.jl`.** The `coo` argument had to be a concrete type for T3, T4 and
   T5 to be written in parallel. It lives with the hook rather than in
   `plans.jl` so that the specified include order (conservative and
   interpolation before plans) still resolves.
5. **`AbstractMissingPolicy` and `AbstractBlockStorage` added.** Dispatch
   supertypes for `Weighted`/`Extensive` and `PerChunk`/`Spilled`; the first is
   exported, the second is not.
6. **T1's own tests live in `runtests.jl`**, not a new file — the tasks doc
   fixes the test file list.

## Open seams for later waves

- **No chart accessor exists.** `hascellchart` is the trait, but nothing in the
  contract exposes the lattice a `BilinearPoint` stencil is written against. T4
  must define one (unexported, in `interpolation.jl`) and log the name. The toy
  space offers `cellsubscript`/`cellposition` as the shape to match.
- **`cellat` and `cellindices` collide with `DiscreteGlobalGrids`' own
  exports.** `using` both packages would make them ambiguous. Recommended T9
  resolution: DGG imports and extends `GlobalRegridding`'s functions rather than
  defining its own, as it already does for `Trees.ncells`/`getcell`.
- **`RasterGrid` and `LazyRegridArray` are exported but undefined.** T2 and T7
  must define exactly those names; the module file cannot be edited to rename
  them.
- **`ChunkedPlan`, `PerChunk`, `Spilled` cannot be constructed.** Their erroring
  inner constructors suppress the defaults; T7/T8 replace the type definitions
  wholesale.
- **`DirectPlan` field order is `(method, missingpolicy, dst_space, src_space,
  block)`.** T5 owns changing it; T7 reads it.

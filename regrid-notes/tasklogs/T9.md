## `DGGSpace` — the space, and its chunking

    DGGSpace(grid::AbstractGrid; chunklevel = nothing, chunkcells = 4096)

Exported. Wraps any `AbstractGrid`; every contract method forwards to the grid,
so no geometry, no tree and no point-location code is new here:

| contract | implementation |
|---|---|
| `ncells`, `getcell` | the grid's — already the same `Trees` bindings |
| `manifold` | `GOCore.best_manifold(grid)` = `Spherical(radius = 1.0)`, identical to `RasterGrid`'s |
| `celltree` | `treeify(grid)` — the `HierarchicalGridCursor`, leaf indices are grid positions |
| `cellcentroid` | `cell_centroid` |
| `cellat` | `cellat(grid, p)` then `cellposition` — the systems' O(1) inverse projections |
| `hascellchart` | `false` (default) — no `BilinearPoint` off a DGGS source |

**Chunks are ancestor cells.** Chunk `c` is one cell of `levelgrid(sys,
chunklevel)` that the grid holds descendants of; its cells are that cell's
`descendant_range` intersected with the grid. `cellindices(space, c)` is
therefore **always a `UnitRange{Int}`** — for a complete level grid it *is* the
`descendant_range`; for a `PartialGrid` it is the interval two binary searches
over the ascending id vector return, contiguous because positions ascend with
ids. Empty ancestors are dropped, so `nchunks` counts occupied ancestors only.

- `chunklevel` defaults to the level minimising `|log(ncells(grid) /
  ncells(sys, a)) - log(chunkcells)|` over `a in first(levels(sys)):level(grid)`
  — density is the *grid's*, so a sparse subset chunks coarser rather than into
  slivers. `chunkcells` defaults to 4096.
- `chunktree` is `DGGChunkTree`, a one-node flat tree with stored caps and chunk
  numbers as leaf indices, modelled on T2's `RasterFlatTree`. A chunk's cap is
  `node_extent(sys, ancestorid)`, the subtree-covering cap — **not** the ancestor
  cell's own boundary cap, which does not cover aperture-7 descendants.
  `chunkextents(space)` returns the stored vector directly.
- `chunkranges(space, chunk, ::NTuple{1,Int})` (T7's seam) is
  `(space.ranges[chunk],)` — no `cellindices` materialisation, though the generic
  1-D path would also have been correct here.
- `subtree(space, inds::AbstractUnitRange)` recognises a chunk and returns the
  hierarchy node rooted at that chunk's ancestor cell, in O(1), with global
  positions as leaf indices; anything else falls back to `CellCapTree`. This is
  T6's `_indexrect` advice for a DGGS, and is what keeps a chunked plan cheap.

**Single-chunk fallback**: a grid with no system, no level, `ncells == 0`, or no
`has_sorted_subtrees` (A5) becomes one whole chunk with a full-sphere cap.
Correct, unpruned. Same for an `AbstractGrid` that is neither a complete level
grid nor a `PartialGrid` — the two shapes whose positions can be placed in the
system's without walking every cell.

## `to` resolution

`regridgrid(x)` is the conversion; `GlobalRegridding._asspace` is extended for
the four data-independent spellings, so no interception is needed for them.

| `to = ` | resolves to |
|---|---|
| `AbstractGrid` (`levelgrid`, `PartialGrid`, `AuthalicGrid`, …) | `DGGSpace(grid)` |
| `CellLookup` | `DGGSpace(PartialGrid(lk))` |
| `CellVector` | `DGGSpace(PartialGrid(cv))` |
| `MultiOrderCellSet` | `DGGSpace(PartialGrid(CellVector(set)))` — its reference level |
| `AbstractHierarchicalGridSystem` | `DGGSpace(levelgrid(sys, arealevel(sys, source)))` |
| `DGGSpace` | itself — the escape hatch for `chunklevel`/`chunkcells` |

A bare system needs the source, which `_asspace` never sees, so the only
interception is one method

    GlobalRegridding.plan_regrid(data::DD.AbstractDimArray; to, from, kwargs...)

which resolves `to` and forwards with `invoke(..., Tuple{Any}, ...)`. `regrid`
and `regrid!` reach it through their own plan construction, so they need no
method. `_asspace(::AbstractHierarchicalGridSystem, name)` throws an
`ArgumentError` naming both ways out, for the non-`DimArray` path.

**Area-matching rule.** `arealevel(sys, space; samples = 256)` = the level
minimising `|log(4π / ncells(sys, l)) - log(median cell area of space)|`,
scanning upward and stopping at the first level at or below the target (areas
shrink monotonically, so that brackets the answer and never overflows
`ncells(sys, l)` at depth). The median is taken over up to 256 cells sampled on
a **golden-ratio stride** rather than a fixed one — a fixed stride on a raster's
row-major cell order can alias onto a single column of latitudes.

## Output wrapping

`regrid(data, plan)` is extended for plans whose destination is a `DGGSpace`
(`DirectPlan` via `invoke`, `ChunkedPlan` by constructing `LazyRegridArray`
directly), and rewraps as `DimArray(values, (Cells(CellLookup(grid)), source's
non-spatial dims...))`. The lazy array keeps its `DiskArrays` laziness inside the
`DimArray`. A non-`DimArray` source comes back as the plain array it was.

**Watch the plan type parameters.** `DirectPlan{<:Any,<:Any,<:DGGSpace}` is
*not* a subtype of `DirectPlan`: a type variable widened past a struct's own
declared bound produces a type outside it, and the method silently never
dispatches. The constants spell the leading bounds
(`<:AbstractRegriddingMethod`, `<:AbstractMissingPolicy`) explicitly. The
"destination axis is the cells" testset is what kills that mutant.

## Name collisions

Mirrors the `Trees` pattern already in the module file. `DiscreteGlobalGrids.jl`
gained

    import GlobalRegridding: cellat, cellindices, regrid, regrid!, plan_regrid

so `DiscreteGlobalGrids.cellat === GlobalRegridding.cellat` and likewise for
`cellindices`: one function per name, no ambiguity for a session holding both.
`cellindices` was removed from the `using .Fallbacks:` list and added to
`fallbacks.jl`'s `import ..DiscreteGlobalGrids:` list, so
`cellindices(::MultiOrderCellSet, l)` now extends the shared binding.
`ncells`, `getcell` and `manifold` were already shared bindings and needed
nothing. Exports added: `regrid`, `regrid!`, `plan_regrid`, `DGGSpace`.

## Deferred, deliberately

- **`missingval` auto-wiring.** T8's kwarg has landed on `regrid`/`plan_regrid`
  and is forwarded through, but nothing reads a Rasters `missingval` from
  metadata; the DimArray-typed `plan_regrid` method is the place to do it.
- **`knownempty` for Zarr-backed DGG cubes.** T8's hook is keyed on the source
  array's own chunks; a DGGS cube over Zarr wants a chunk-presence adapter. IO
  track.
- **Hierarchical chunk tree.** `DGGChunkTree` is flat, so chunk discovery is a
  cap scan over `nchunks`. The ancestor level grid's own cursor would prune
  level by level, but its leaf `node_extent` is the ancestor's *cell* cap, which
  under-covers aperture-7 subtrees; giving the cursor a subtree-covering leaf
  extent is the fix.
- **`_chunkcursor` builds a `HierarchicalGridCursor` from its field list**
  (`grid, system, top_level, leaf_level, bucket_size, level, id, first_index,
  last_index, selection`). That coupling belongs behind a `Fallbacks` helper —
  "the node of this grid's tree rooted at cell `c` over positions `lo:hi`".
- **Docs.** `cellat` and `cellindices` are now `GlobalRegridding` bindings
  documented from this package; a Documenter `checkdocs` pass has not been run
  against that.
- Regridding **onto a raster from a DGGS cube** still returns T6's flat
  `Dim{:Cell}` axis; nothing here reshapes it.
